口径说明与数据来源

算力口径：FP16/BF16、FP8、FP4、INT8 均为稠密（dense）峰值。厂商标注的稀疏值通常是稠密的 2 倍；标 † 的数值由官方稀疏 / 低精度口径折算，或按同代产品规格回推，不是官方公布值，仅用于同表横向比较。

显存与带宽：显存为单卡可用容量（部分型号物料容量略高）；带宽为峰值理论值。

功耗：整卡 TDP / 板卡功耗，不含整机与散热。Rubin 标准版 1800W、增强版 2300W；B300 的 HGX 版本可配置至 1100W。

形态：SXM 为 NVIDIA 模块接口；OAM 为 OCP 加速器模块；PCIe 为独立卡。部分型号同时提供 OAM 与 PCIe 版本，筛选时两边都会计入。

可比性：跨厂商峰值算力不能直接等价。训练更看互联与集群规模，推理更看显存容量 / 带宽与软件栈；实际性能取决于模型、batch、并行策略与框架适配。

数据来源：逐项按厂商官网核对。NVIDIA 取各产品规格页与 HGX 页（L40S 规格页无 FP4 一行，故留空）；AMD 取 Instinct 规格表，并按官方稠密口径分别录入 MI350X、MI355X 与 PCIe 形态的 MI350P、EAM 形态的 MI455X；Intel 取 Gaudi 3 规格页。华为昇腾取 官网加速卡技术规格的逐个 tab：Atlas 150 / 350（同为 Ascend 950PR，只差 84GB 与 112GB）、Atlas 300I A2（32GB / 0.8TB·s 与 64GB / 1.6TB·s 两档）、Atlas 300I Duo（96GB / 48GB 两档）都按官网分档各占一行，不取中间值；昇腾 910C 官网无单卡规格页，其显存与功耗仍为媒体口径。平头哥真武系列官方只公布显存、内存带宽与片间互联：M890、V900 的单卡 FLOPS 未公布，一律留空不用估算值填表；810E 官网公布 96GB HBM2e 与 2.7TB/s，FP16 120 TFLOPS 为按 M890 回推的估算值，标 †。寒武纪官网仅收录思元 370 / 270 系列，590、690 无任何官方规格页，标注为第三方口径；沐曦官网 C500 页只公布 64GB 显存与最大 350W，算力取自第三方汇总。

显存估算：“模型资源估算”按阿里云 PAI 简易估算法实现——权重按参数量 × 字节、激活与 KV Cache 以“模型显存 10%（batch / 并发 1、序列 2048、2 字节）”为基线线性放大、LoRA 系列可训练参数取总参数 1%、其他开销固定 2 GB。结果为理论下界，未包含张量 / 流水并行的切分冗余、激活重算、通信与算子缓冲；实际可跑的最优并行方案与卡数需以框架实测为准。
